# Atatürk: Bir Milletin Uyanışı

Interaktif bir dijital anıtsama deneyimi ile Türkiye Cumhuriyeti'nin kurucusu Gazi Mustafa Kemal Atatürk'ün hayatını, devrimlerini ve Kurtuluş Savaşı mücadelesini keşfedin.

**[ByGhost site byghost.tr](https://byghost.tr)**

## 📖 Proje Özeti

Bu proje, Mustafa Kemal Atatürk'ün hayatı boyunca gerçekleşen önemli olayları, verdiği mücadeleleri ve gerçekleştirdiği inkılapları interaktif bir şekilde sunmayı amaçlamaktadır. Ziyaretçiler, kronolojik olarak gelişen bir zaman çizelgesi üzerinde Atatürk'ün kişisel ve siyasi yaşamını takip edebilir, harita üzerinden Kurtuluş Savaşı cephesindeki gelişmeleri inceleyebilir ve Cumhuriyet'in temel ilkelerini öğrenebilirler.

## 🌟 Özellikler

- 🕰️ **İnteraktif Zaman Çizelgesi**: Atatürk'ün hayatındaki önemli dönüm noktaları
- 🗺️ **Kurtuluş Savaşı Haritası**: Savaşın tüm cephesindeki gelişmeler ve önemli savaşlar
- 💡 **Atatürk İlkeleri**: Cumhuriyetin temel ilkeleri ve anlamları
- 🎭 **Modern UI/UX**: Akıcı animasyonlar ve kullanıcı dostu arayüz
- 📱 **Tamamen Responsive**: Tüm cihaz boyutlarında uyumlu tasarım

## 🛠️ Teknoloji Yığını

- **React 19** - Modern kullanıcı arayüzü geliştirme
- **TypeScript** - Tip güvenliği ve geliştirme kolaylıkları
- **Vite** - Hızlı geliştirme ve derleme süreci
- **Tailwind CSS** - Utility-first CSS framework
- **Framer Motion** - Gelişmiş animasyonlar
- **Lucide Icons** - Modern ikon seti

## 🚀 Yerel Ortamda Çalıştırma

### Gereksinimler

- Node.js (v16 veya üzeri)
- npm (Node.js ile birlikte gelir)

### Kurulum Adımları

1. Bağımlılıkları yükleyin:
   ```bash
   npm install
   ```

2. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```

3. Tarayıcınızda `http://localhost:3000` adresine gidin

### Diğer Komutlar

```bash
# Production için derleme
npm run build

# Derlenmiş uygulamayı önizleme
npm run preview
```
